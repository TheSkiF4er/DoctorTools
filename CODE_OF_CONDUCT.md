# Кодекс поведения

В проекте ожидается техническое, уважительное и предметное общение.

Недопустимо:

- оскорблять участников;
- публиковать чужие приватные данные;
- выкладывать вредоносный код без защитного контекста;
- превращать технические обсуждения в личные конфликты.

Критика приветствуется, если она помогает улучшить CraftDoctor: точнее проверка, меньше false positive, лучше отчёт, чище код, понятнее рекомендация.
