# Участие в разработке CraftDoctor

Спасибо за интерес к проекту.

## Язык

Проект ведётся исключительно на русском языке:

- README;
- GitFlic Wiki;
- CLI help;
- сообщения CLI;
- отчёты;
- примеры конфигурации;
- шаблоны задач и merge request;
- комментарии пользовательского уровня.

Английский допустим только там, где он технически необходим: имена пакетов, идентификаторы, протоколы, названия стандартов, CLI-флаги, JSON/YAML-ключи и имена файлов.

## Как предлагать изменения

1. Создайте отдельную ветку.
2. Опишите проблему или улучшение.
3. Добавьте тесты, если изменение затрагивает анализаторы или парсинг.
4. Проверьте сборку:

```bash
go test ./...
go build ./cmd/craftdoctor
```

## Правила для проверок

Каждая новая проверка должна иметь:

- стабильный `ID`;
- уровень серьёзности;
- категорию;
- понятное описание на русском языке;
- практическую рекомендацию.

## Документация

Основная документация ведётся в GitFlic Wiki. Папку `docs/` не создавать без отдельного решения.
